FOTO PROFIL PENGURUS — PORTAL HAAK
====================================

Tempatkan foto pengurus dalam format JPEG (.jpeg/.jpg) sesuai nama file yang dipakai di js/app.js.

Contoh:
01-rp-henrikus-suwaji.jpeg
02-rm-hector-javier-cortes-tornel.jpeg
...
25-yohanes-wuryanto.jpeg

Rekomendasi:
- Rasio 1:1 (square)
- Minimal 600 × 600 px
- JPEG/JPG
- Foto formal, jelas, dan layak untuk publikasi

Jika file foto belum tersedia atau gagal dimuat, portal otomatis menampilkan inisial nama sebagai fallback.
