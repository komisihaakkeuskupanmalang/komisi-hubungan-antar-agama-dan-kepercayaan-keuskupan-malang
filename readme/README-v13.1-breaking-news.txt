- Breaking News kini berbentuk marquee/pesan berjalan satu baris.

- Ticker dapat diklik menuju detail artikel.
- Animasi berhenti saat hover/focus dan otomatis mengikuti prefers-reduced-motion.
- Layout mobile dipadatkan agar tidak mengganggu Hero atau navigasi.
