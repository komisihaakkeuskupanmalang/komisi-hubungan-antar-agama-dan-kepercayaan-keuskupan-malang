PORTAL BERITA HAAK — v15
PROFIL DETAIL PENGURUS + PENCARIAN CERDAS

Pembaruan v15 berfokus pada halaman Daftar Pengurus.

FITUR BARU
1. Profil Detail Pengurus
   - Setiap baris pengurus memiliki tombol "Lihat Profil".
   - Nama pengurus juga dapat ditekan untuk membuka profil.
   - Profil ditampilkan dalam modal responsif.
   - Menampilkan nama, jabatan, kelompok, dan fokus pelayanan.
   - Modal dapat ditutup melalui tombol X, klik area luar, atau tombol Escape.
   - Mendukung keyboard focus pada tombol tutup.

2. Pencarian Pengurus Lebih Pintar
   - Mencari nama, jabatan, kelompok/bidang, dan kata kunci.
   - Normalisasi huruf/aksen untuk hasil pencarian yang lebih konsisten.
   - Ranking hasil berdasarkan relevansi.
   - Toleransi kesalahan pengetikan sederhana (fuzzy matching).
   - Menampilkan hingga 5 saran pengurus saat mengetik.
   - Filter kelompok jabatan tetap dapat digunakan bersama pencarian.

PERBAIKAN
- Struktur halaman Daftar Pengurus v14 dipertahankan.
- Data 25 entri pengurus tetap tersedia.
- Fungsi cetak dan reset tetap berjalan.
- Tampilan desktop dan mobile diperbarui agar fitur baru tidak menyebabkan overflow.
- PWA cache dinaikkan ke v15 agar aset baru tidak tertahan oleh cache versi lama.

CATATAN DATA
Data nama dan jabatan tetap mengikuti daftar pengurus yang menjadi dasar pembaruan portal. Informasi fokus pelayanan pada profil merupakan deskripsi fungsional berdasarkan jabatan, bukan data pribadi tambahan.
