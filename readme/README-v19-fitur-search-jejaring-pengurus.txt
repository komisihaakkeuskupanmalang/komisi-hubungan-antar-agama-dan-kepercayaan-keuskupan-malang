PORTAL BERITA HAAK — v19.0

Fokus pengembangan:
1. Search Experience dikembangkan dari global search yang sudah ada, bukan membuat pencarian baru. Saran kini lebih relevan, menampilkan metadata, topik, jejaring, kolaborasi, riwayat, dan petunjuk hasil lengkap.
2. Profil Jejaring diperdalam dengan statistik publikasi/kolaborasi/topik, lokasi, topik terkait, kolaborasi, tombol berbagi, dan publikasi terkait. Data eksternal hanya ditampilkan bila tersedia.
3. Profil Pengurus diperdalam di modal yang sudah ada: kelompok, fokus pelayanan, jumlah publikasi terkait, topik keterlibatan, jejak publikasi, dan salin tautan profil.
4. Tidak membuat halaman pencarian baru dan tidak mengubah fondasi navigasi.
